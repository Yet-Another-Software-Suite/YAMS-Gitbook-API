# Swerve drive

Complete swerve drive implementation with kinematics and pose estimation.

Robot code imports `SwerveDrive` and `SwerveInputStream` from `yams.commands2.swerve` (Commands v2) or `yams.commands3.swerve` (Commands v3), and `SwerveDriveConfig` from `yams.commands2.config` or `yams.commands3.config`. `SwerveModule`, `SwerveModuleConfig` and `GyroAxis` come from `yams.core`.
